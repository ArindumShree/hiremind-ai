# Documentation

This folder holds extended project documentation.

The primary project docs live at the repository root:

- `README.md` — project overview, setup, run instructions.
- `ARCHITECTURE.md` — architectural style, tech decisions, layer design.
- `ROADMAP.md` — stage-by-stage product roadmap.
- `TASKS.md` — current sprint task tracking.
- `MEMORY.md` — long-term session memory (append-only history).
- `AI_CONTEXT.md` — current project state snapshot for AI assistants.

Per-stage design notes and ADRs can be added here as the project grows.
